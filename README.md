# Random Password Generator

## About the Project
A Python-based desktop application that generates random passwords using letters, digits and special characters.

## Features
- Custom password length (8–128 characters)
- Random password generation
- Password strength indicator
- Copy password to clipboard
- Input validation
- Graphical interface using Tkinter

## Technologies Used
- Python
- Tkinter
- Secrets
- String

## How to Run
1. Install Python.
2. Download this repository.
3. Open the project folder in terminal.
4. Run `py password_generator.py`.

- Python functions

- Secure random generation
